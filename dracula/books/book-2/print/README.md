# Book II print layout (draft, 8 Nov 2026)

Same layout as Book I: 11 × 8.5 in landscape, white text pages on the left and paintings on twilight-navy pages on the right.

- `data.json`: Chapters V–XVI built from the cue sheets (ep05–ep16) and the pictures already placed in art.json. One painting per spread is chosen from the scenes on that spread.
- Front: the Book II cover (Lucy at the gate) as the title page, the foreword "Keys to this Blood" (the same as Book I, with the Book II lines changed), then the credits. Section cards (Whitby, The Blood, The Un-Dead) come before V, IX and XIII. Each chapter has its card, then an opener page with a QR code that plays the chapter (`part-2/?ch=N`).
- `book.html` and `render.js` work the same way as Book I. `render.js` needs `ad` to link to Amenti-Studios/dracula and `art` to link to Amenti-Readings/dracula/art.
- The draft comes to 221 pages.
