# Dracula · the books

The print files for each book. The web pages stay in `../part-1/` and `../part-2/` (the chapter QR codes will point there).

| Folder | Book | Chapters |
| --- | --- | --- |
| `book-1/` | I · The Castle | I–IV |
| `book-2/` | II · Lucy | V–XVI |
| `book-3/` | III · The Hunt | XVII–XXVII (to come) |

In each folder:

- `cover.html` — the cover, editable. Open it in Safari to see it; `?front` shows the front alone. Change words where they sit; Safari › File › Export as PDF makes a print PDF (23 × 8.75 in wrap; 11.125 × 8.75 in front).
- `cover-wrap-print.jpg`, `cover-front-print.jpg` — print renders (6624 × 2520 px wrap). Re-rendered by Claude after any edit to `cover.html`.
- `BUILD.md` — the book's build document.
